### 이 기록을 어떻게 읽어야 하는가

**원어민 검수가 아니다.** 라벨을 쓴 것도 언어모델이고 확인한 것도 언어모델이다. 둘은 학습
분포를 상당히 공유하므로, 서로의 판단이 독립적이라고 보기 어렵다.

**그리고 시트가 동의를 유도하는 형태였다.** 각 줄에 판정과 그 근거를 미리 적어 두고
"맞습니까" 를 물었다. 모델은 그런 질문에 동의하는 쪽으로 기운다(acquiescence). 그래서
"전부 ○" 는 **"명백한 오류는 없다"** 정도로 읽어야 하고, **"라벨이 옳다"** 로 읽으면 안 된다.
다음에 같은 부탁을 할 때는 판정을 지운 시트를 주고 빈칸을 채우게 하는 쪽이 낫다 —
그렇게 받은 답이 우리 라벨과 일치하면 그건 훨씬 무거운 증거가 된다.

**그래도 값이 있었던 부분**은 Gemini 의 §3 이다. 우리 평가셋에 없던 표현
(「ご希望に添いかねます」「必要に応じてご連絡」「持ち帰らせていただく」「お声がけいたします」
「善処いたします」「せっかくのご提案ですが」)을 열 건 제시했고, 그중 어느 것도 당시 우리
사전에 들어 있지 않았다. 제안 자체가 새 문장을 찾아 준 것이지 라벨을 보증한 것은 아니므로,
평가셋에 넣을 때 라벨은 처음부터 다시 판정했다.

### 아직 받지 못한 것

일본어 모어 화자의 검수. 관행에 기대는 두 축(쿠션어·확답 회피)은 공표된 기준이 없으므로
사람의 읽기가 필요하고, 그것만이 위의 두 기록을 대신할 수 있다.
